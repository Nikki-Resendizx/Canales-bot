# Canales-bot

Bot multicanal de Telegram para completar y editar publicaciones automáticamente.

Funciones: múltiples canales, plantillas por canal y tipo de contenido, hashtags, botones inline, corrección de texto y panel /admin.

No incluye módulo de modelos.

Variables: BOT_TOKEN, ADMIN_IDS.

El bot debe ser administrador de cada canal con permiso para editar mensajes.

Hosting: npm install && npm start.
